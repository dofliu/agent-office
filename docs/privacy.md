# 隱私與安全

部署前請先讀完。重點：**看板沒有「只給自己看」的模式**，讀取是公開的；只有寫入受密碼保護。

## 哪些東西是公開的

| 項目 | 誰看得到 | 原因 |
|---|---|---|
| 網站與原始碼 | 所有人 | GitHub Pages 與公開 repo |
| `js/config.js` 裡的 email、TEAM、暱稱、Apps Script 網址 | 所有人 | 寫在公開的原始碼裡 |
| 三個資料夾裡**所有 JSON 的內容**（最近 120 天）：工作紀錄的主題與內容摘要、會議議程與每則發言、會議結論、指令與回報 | 任何打開網站或知道 Apps Script 網址的人 | Apps Script 必須設成「所有人」可存取，看板才讀得到 |
| 這些內容裡寫到的連結（例如分享網址、資料夾 ID） | 同上 | 內容會原樣顯示 |

所以：**不要讓代理人在紀錄、會議或指令裡寫機密**，例如密碼、API 金鑰、帶分享金鑰的連結、學生個資、未公開的研究數據。
工作紀錄技能只記主題、100 字內的摘要、時間、帳號與 TEAM，不記整段對話；但會議發言與指令內容是全文。

## 哪些東西不公開

| 項目 | 說明 |
|---|---|
| Claude 對話本身 | 看板只讀 Drive 裡的 JSON 檔，看不到任何對話 |
| Google Drive 資料夾與檔案 | 保持私人時，別人點檔案連結會被要求權限；只有 Apps Script 彙整出來的 JSON 內容會外流 |
| Drive 裡其他檔案 | Apps Script 只讀這三個資料夾 |
| 管理密碼 `ADMIN_KEY` | 存在 Apps Script 的「指令碼屬性」，不在原始碼裡；看板只把它存在你自己瀏覽器的 localStorage |

## 管理密碼

- 沒有密碼，任何人都**不能寫入**：不能發起會議、發言、下指令、改 TEAM 或刪紀錄。
- 密碼請設 20 字以上的隨機字串。Apps Script 沒有限制嘗試次數，短密碼可能被猜中。
- 在公用電腦登入後，用完按「管理登入 → 登出管理模式」。
- 懷疑外洩時，到 Apps Script「專案設定 → 指令碼屬性」改 `ADMIN_KEY`，舊密碼立刻失效（不用重新部署）。
- 寫入只能在三個資料夾內新增檔案、移到垃圾桶（30 天內可在 Drive 還原）或改 TEAM；不能動 Drive 其他地方。

## 想要不公開，有哪些做法

| 做法 | 效果 | 代價 |
|---|---|---|
| 在 Apps Script 加「讀取密碼」，看板第一次打開時要輸入 | 沒密碼的人看不到資料（網站外殼仍公開） | 需要改 `Code.gs` 與 `js/app.js`；每台裝置要輸入一次 |
| Apps Script 改成「只有我（或網域內的人）」可存取 | 只有登入 Google 的指定帳號讀得到 | 靜態網頁跨網域讀取會被 Google 擋，看板要改成在 Apps Script 內提供網頁 |
| 不開 GitHub Pages，只在本機開 | 網站不公開 | Apps Script 網址仍要保密，否則一樣讀得到 |

原作者的看板目前還在開發中，選擇**公開讀取、暫不加讀取密碼**（2026-11-03 決定），並約定代理人不在紀錄、會議與指令裡寫機密。
若你的資料不適合公開，部署前先做上面任一種。
