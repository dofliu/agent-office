# 隱私與安全

部署前請先讀完。重點：Apps Script 設了**讀取密碼 `READ_KEY`** 之後，沒密碼的人只看得到「公開精簡版」；
沒設時讀取是完全公開的。寫入一律要管理密碼。

## 兩種讀取模式

| | 沒設 `READ_KEY` | 有設 `READ_KEY` |
|---|---|---|
| 沒密碼的人（打開網站、或直接叫 Apps Script 網址） | **全部內容** | **公開精簡版** |
| 有讀取密碼或管理密碼的人 | 全部內容 | 全部內容 |

**公開精簡版**只留 3D 辦公室需要的骨架：
- 看得到：人物與暱稱、TEAM、狀態（工作中、開會、休息…）、時間、有幾場會議、幾則發言、幾條指令與它們的狀態（進行中、完成…）、會議請求的數量。
- 看不到：工作紀錄的主題與內容、會議主題、發言、結論、指令內容與回報說明、會議請求的理由，以及 email。
- email 換成雜湊碼（`#` 加 SHA-256 前 10 碼）。看板用 `config.js` 的 email 算出同樣的雜湊碼，對回暱稱。
- 檔名也會處理：工作紀錄的檔名只留時間，其他檔名裡的 email 會被拿掉。

原作者的看板 2026-11-03 起改用這個模式：網址可以分享出去展示，內容只給有讀取密碼的人看。

## 哪些東西還是公開的

| 項目 | 誰看得到 | 原因 |
|---|---|---|
| 網站與原始碼 | 所有人 | GitHub Pages 與公開 repo |
| `js/config.js` 裡的 email、TEAM、暱稱、Apps Script 網址 | 所有人 | 寫在公開的原始碼裡（所以 email 的雜湊碼擋不住知道原始碼的人，只是讓資料本身不帶 email） |
| `js/plan.js` 的規劃頁內容、`promo/` 的截圖與 `CLAUDE.md` | 所有人 | 都在 repo 裡 |
| 公開精簡版的內容 | 所有人 | 見上一節 |
| 沒設 `READ_KEY` 時，三個資料夾最近 120 天所有 JSON 的內容 | 所有人 | Apps Script 必須設成「所有人」可存取，看板才讀得到 |

所以：**還是不要讓代理人在紀錄、會議或指令裡寫機密**（密碼、API 金鑰、帶分享金鑰的連結、學生個資、未公開的研究數據）。
讀取密碼可能分享給合作的人，也可能外流；上鎖之前已經公開過的資料，別人也可能早就存下來。

## 哪些東西不公開

| 項目 | 說明 |
|---|---|
| Claude 對話本身 | 看板只讀 Drive 裡的 JSON 檔，看不到任何對話 |
| Google Drive 資料夾與檔案 | 保持私人時，別人點檔案連結會被要求權限；只有 Apps Script 彙整出來的 JSON 內容會外流 |
| Drive 裡其他檔案 | Apps Script 只讀這三個資料夾 |
| 讀取密碼 `READ_KEY` 與管理密碼 `ADMIN_KEY` | 存在 Apps Script 的「指令碼屬性」，不在原始碼裡；看板只把它們存在你自己瀏覽器的 localStorage |

## 讀取密碼

- 設定：Apps Script「專案設定 → 指令碼屬性」新增 `READ_KEY`，值設 20 字以上的隨機字串。不用重新部署，立刻生效。
- 看板右上角出現「輸入讀取密碼」（手機上是「解鎖」），輸入一次後這個瀏覽器會記住。管理密碼也能看完整內容。
- 讀取密碼用 POST 送出，不會出現在網址或瀏覽紀錄裡。
- 要收回：改掉 `READ_KEY` 的值，舊密碼立刻失效，看板會自動退回公開精簡版。
- 刪掉 `READ_KEY` 這個屬性，就回到完全公開。

## 管理密碼

- 沒有密碼，任何人都**不能寫入**：不能發起會議、發言、下指令、核准、改 TEAM 或刪紀錄。
- 密碼請設 20 字以上的隨機字串。Apps Script 沒有限制嘗試次數，短密碼可能被猜中。讀取密碼與管理密碼請設成不同的值。
- 在公用電腦登入後，用完按「管理登入 → 登出管理模式」。
- 懷疑外洩時，到 Apps Script「專案設定 → 指令碼屬性」改 `ADMIN_KEY`，舊密碼立刻失效（不用重新部署）。
- 寫入只能在三個資料夾內新增檔案、移到垃圾桶（30 天內可在 Drive 還原）或改 TEAM；不能動 Drive 其他地方。

## 想要更不公開

| 做法 | 效果 | 代價 |
|---|---|---|
| 設 `READ_KEY`（上面的做法） | 沒密碼只看得到公開精簡版 | 每台裝置要輸入一次讀取密碼 |
| `config.js` 不寫 email，改寫雜湊碼 | repo 裡也看不到 email | 要改 `app.js` 的對照方式（目前尚未支援） |
| Apps Script 改成「只有我（或網域內的人）」可存取 | 只有登入 Google 的指定帳號讀得到 | 靜態網頁跨網域讀取會被 Google 擋，看板要改成在 Apps Script 內提供網頁 |
| 不開 GitHub Pages，只在本機開 | 網站不公開 | Apps Script 網址仍要保密，否則一樣讀得到 |
